The HTML id Attribute

El atributo id se usa para especificar un id unico para un elemento HTML. No puede haber mas de un elemento con el mismo id en un documento HTML.

The id Attribute

El valor del atributo id debe ser unico dentro del documento HTML. Se usa para apuntar a una declaracion de estilo especifica en una hoja de estilos, y tambien es usado por JavaScript para acceder y manipular el elemento con ese id especifico.

La sintaxis es: un simbolo numeral (#) seguido del nombre del id, y luego las propiedades CSS entre llaves.

My Header

Nota: el nombre del id distingue mayusculas de minusculas. Debe contener al menos un caracter, no puede empezar con un numero, y no debe contener espacios en blanco.

Difference Between Class and ID

Un nombre de clase puede ser usado por multiples elementos HTML, mientras que un nombre de id debe ser usado por un solo elemento dentro de la pagina.
