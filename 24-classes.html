The class Attribute

El atributo class especifica una o mas clases para un elemento HTML. Las clases son usadas por CSS y JavaScript para seleccionar y acceder a elementos especificos.

Multiples elementos con la misma clase

Varios elementos HTML pueden compartir la misma clase.

London

London is the capital of England.

Paris

Paris is the capital of France.

Tokyo

Tokyo is the capital of Japan.

Usar class con elementos especificos (element.class)

Para seleccionar solo un tipo de elemento con una clase especifica, se escribe el nombre del elemento, un punto, y el nombre de la clase.

Este parrafo tiene la clase large, que aumenta el tamano de letra.

Multiples clases en un mismo elemento

Un elemento HTML puede tener mas de una clase, separadas por un espacio.

Header 1 con dos clases

A paragraph.

Sintaxis del atributo class

El atributo class no debe empezar con un numero, ya que puede causar problemas en algunos navegadores.

Class y JavaScript

La clase tambien puede ser usada por JavaScript para acceder y manipular elementos con ese nombre de clase especifico.
