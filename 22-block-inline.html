HTML Block and Inline Elements

Block-level Elements

Un elemento de bloque siempre empieza en una nueva linea y ocupa todo el ancho disponible. Los navegadores agregan automaticamente algo de espacio (margen) antes y despues del elemento.

Dos elementos de bloque comunes son p y div.

Hello World

Hello World

Inline Elements

Un elemento en linea no empieza en una nueva linea y solo ocupa el ancho necesario. Nota: un elemento en linea no puede contener un elemento de bloque.

This is a span element inside a paragraph.

The div Element

El elemento div se usa frecuentemente como contenedor para otros elementos HTML. No tiene atributos obligatorios, pero style, class e id son comunes. Usado junto con CSS, div puede estilizar bloques de contenido.

London

London is the capital city of England. It is the most populous city in the United Kingdom, with a metropolitan area of over 13 million inhabitants.

The span Element

El elemento span es un contenedor en linea usado para marcar una parte de un texto o documento.

My mother has blue eyes and my father has dark green eyes.
