HTML Forms

Un formulario HTML se usa para recolectar informacion ingresada por el usuario. La informacion normalmente se envia a un servidor para su procesamiento.

The form Element

El elemento form es un contenedor para distintos tipos de elementos de entrada, como: campos de texto, checkboxes, botones de radio, botones de envio, etc.

The input Element

El elemento input se puede mostrar de varias formas, dependiendo del atributo type.




Nota: el formulario en si no es visible. Tambien, el ancho por defecto de un campo de entrada es 20 caracteres.

The label Element

El elemento label define una etiqueta para varios elementos de formulario, y es util para lectores de pantalla, ya que leeran en voz alta la etiqueta cuando el usuario enfoque el campo.

El elemento label tambien ayuda a usuarios que tienen dificultad para hacer clic en areas muy pequenas (como botones de radio o checkboxes), ya que cuando el usuario hace clic en el texto dentro del label, tambien se activa el radio button o checkbox.

El atributo for de la etiqueta label debe ser igual al atributo id del elemento input para vincularlos entre si.

Radio Buttons

El input type="radio" define un boton de radio. Los botones de radio permiten al usuario seleccionar UNA opcion entre un numero limitado de opciones.

Checkboxes

El input type="checkbox" define un checkbox. Los checkboxes permiten al usuario seleccionar CERO o MAS opciones de un numero limitado de opciones.



The Submit Button

El input type="submit" define un boton para enviar los datos del formulario a un manejador de formularios. El manejador es tipicamente un archivo del lado del servidor con un script para procesar la informacion ingresada.

El manejador se especifica en el atributo action del formulario.




Importante: el atributo name

Nota: si se omite el atributo name del input, los datos de ese campo no se enviaran en absoluto al enviar el formulario.
