HTML Form Attributes

The action Attribute

El atributo action define la accion a realizar cuando se envia el formulario. Normalmente, los datos del formulario se envian a un archivo del servidor cuando el usuario hace clic en el boton de envio.




Si se omite el atributo action, los datos del formulario se envian a la pagina actual.

The target Attribute

El atributo target especifica donde se debe mostrar la respuesta despues de enviar el formulario. Valores posibles: _blank, _self, _parent, _top.




The method Attribute

El atributo method especifica el metodo HTTP a usar al enviar los datos del formulario. Los datos pueden enviarse como variables de URL (method="get") o como una transaccion HTTP post (method="post").




Notas sobre GET

GET agrega los datos del formulario a la URL, en pares nombre/valor. Nunca se debe usar GET para enviar informacion sensible, ya que el nombre y valor se muestran en la URL.

Notas sobre POST

POST agrega los datos del formulario dentro del cuerpo de la solicitud HTTP (los datos enviados no se muestran en la URL). POST no tiene limitaciones de tamano, y se puede usar para enviar grandes cantidades de datos. Siempre se recomienda usar POST si los datos del formulario contienen informacion sensible o personal.




The autocomplete Attribute

El atributo autocomplete especifica si un formulario debe tener el autocompletado activado o desactivado. Cuando esta activado, el navegador completa automaticamente los valores basandose en valores que el usuario ha ingresado antes.




The novalidate Attribute

El atributo novalidate es un atributo booleano. Cuando esta presente, especifica que los datos del formulario no deben validarse al enviarse.
