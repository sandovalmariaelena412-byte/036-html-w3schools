HTML Input Types

El elemento input puede mostrarse de muchas formas, dependiendo del atributo type.

type="text"

Define un campo de entrada de una sola linea para texto.




type="password"

Define un campo de contrasena. Los caracteres de este campo se enmascaran (se muestran como asteriscos o puntos).




type="submit"

Define un boton para enviar los datos del formulario a un manejador de formularios.






Si se omite el atributo value, el boton tendra un texto por defecto:






type="reset"

Define un boton que reinicia todos los valores del formulario a sus valores iniciales.






type="radio"

Define un boton de radio. Permite al usuario seleccionar UNA opcion entre varias.

Choose your favorite Web language:



type="checkbox"

Define un checkbox. Permite al usuario seleccionar CERO o MAS opciones.



type="color"

Permite al usuario seleccionar un color con un selector de color.

type="date"

Permite al usuario seleccionar una fecha con un selector de fecha.

Restringir fechas con min y max



type="datetime-local"

Permite al usuario seleccionar fecha y hora (sin zona horaria).

type="email"

Se usa para campos de entrada que deben contener una direccion de correo electronico. Se valida automaticamente al enviar.

type="image"

Define una imagen como boton de envio.

type="file"

Define un campo de seleccion de archivo y un boton "Examinar" para subir archivos.

type="hidden"

Define un campo de entrada oculto (no visible para el usuario). Se usa para almacenar datos que deben enviarse al servidor, como un id de cliente.



type="month"

Permite al usuario seleccionar un mes y ano.

type="number"

Define un campo numerico. Se pueden restringir los valores permitidos.

Uso del atributo step

type="range"

Define un control deslizante (slider) para elegir un valor dentro de un rango.

type="search"

Se usa para campos de busqueda de texto.

type="tel"

Se usa para campos que deben contener un numero de telefono. Se puede validar con el atributo pattern.

type="time"

Permite al usuario seleccionar una hora.

type="url"

Se usa para campos que deben contener una direccion URL. Se valida automaticamente al enviar.

type="week"

Permite al usuario seleccionar una semana y ano.
