HTML Symbol Entities

Los simbolos o letras que no estan presentes en el teclado se pueden agregar a HTML usando entidades: el nombre de la entidad o el numero de entidad (una referencia decimal o hexadecimal).

Ejemplo: mostrar el signo de euro

I will display €

Las tres lineas anteriores muestran el mismo simbolo, usando el nombre de entidad, el numero decimal, y el numero hexadecimal respectivamente.
