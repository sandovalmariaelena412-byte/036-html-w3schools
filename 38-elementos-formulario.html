HTML Form Elements

El elemento form puede contener uno o mas de los siguientes elementos: input, label, select, textarea, button, fieldset, legend, datalist, output, option, optgroup.

The input Element

Uno de los elementos de formulario mas usados es el elemento input. Se puede mostrar de varias formas, dependiendo del atributo type.

The select Element

El elemento select define una lista desplegable.

El elemento option define las opciones que se pueden seleccionar. Por defecto, la lista muestra el primer elemento como seleccionado.

The selected Attribute

Para definir una opcion preseleccionada, se agrega el atributo selected al elemento option.

The textarea Element

El elemento textarea define un campo de texto multilinea.

El atributo rows especifica el numero de lineas visibles; el atributo cols especifica el ancho visible del area de texto.

The button Element

El elemento button define un boton clickeable.

Nota: siempre se debe especificar el atributo type para el elemento button, ya que distintos navegadores pueden usar tipos por defecto diferentes.

The fieldset and legend Elements

El elemento fieldset se usa para agrupar datos relacionados en un formulario. El elemento legend define un titulo para el elemento fieldset.

The datalist Element

El elemento datalist especifica una lista de opciones predefinidas para un elemento input. Los usuarios veran una lista desplegable de opciones predefinidas mientras escriben. El atributo list del input debe hacer referencia al atributo id del datalist.

The output Element

El elemento output representa el resultado de un calculo.
