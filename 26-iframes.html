HTML Iframes

Un iframe HTML es usado para mostrar una pagina web dentro de otra pagina web. La etiqueta iframe especifica un marco en linea.

Consejo: siempre es buena practica incluir un atributo title para el iframe, ya que los lectores de pantalla lo usan para leer el contenido.

Ejemplo basico

Set Height and Width

Se puede usar el atributo height y width, o la propiedad CSS height y width, para especificar el tamano del iframe.

Remove the Border

Por defecto, un iframe tiene un borde a su alrededor. Se puede eliminar con la propiedad CSS border.

Target for a Link

Un iframe puede usarse como el destino (target) de un enlace. El atributo target del enlace debe coincidir con el atributo name del iframe.
