HTML Lists

Las listas en HTML permiten agrupar elementos relacionados.

Unordered HTML List

Una lista desordenada empieza con la etiqueta ul. Cada elemento empieza con la etiqueta li. Por defecto se marcan con vinetas.

  • Coffee
  • Tea
  • Milk

Nested HTML Lists

Las listas pueden anidarse (una lista dentro de otra). Un elemento li puede contener una nueva lista, o incluso otros elementos como imagenes y enlaces.

  • Coffee
  • Tea
    • Black tea
    • Green tea
  • Milk

Horizontal List with CSS

Las listas se pueden estilizar de muchas formas con CSS; una forma popular es convertirlas en un menu horizontal.

  • Home
  • News
  • Contact
  • About

Ordered HTML List

Una lista ordenada empieza con la etiqueta ol. Cada elemento empieza con la etiqueta li. Por defecto se marcan con numeros.

  1. Coffee
  2. Tea
  3. Milk

Ordered List - Type Attribute (1, A, a, I, i)

El atributo type de la etiqueta ol define el tipo de marcador de la lista.

  1. Coffee
  2. Tea
  1. Coffee
  2. Tea

  1. Coffee

Ordered List - Start Attribute

Por defecto, una lista ordenada empieza a contar desde 1. El atributo start permite iniciar desde otro numero.

  1. Coffee
  2. Tea
  3. Milk

Ordered List - Reversed Attribute

El atributo reversed hace que la lista cuente hacia abajo en vez de hacia arriba.

  1. Coffee
  2. Tea
  3. Milk

Ordered List - Value Attribute

El atributo value en un solo li fuerza a que ese elemento tenga un numero especifico.

  1. Coffee
  2. Tea
  3. Milk

HTML Description Lists

Una lista de descripcion es una lista de terminos con su descripcion. La etiqueta dl define la lista, dt define el termino, y dd describe el termino.

Coffee
- black hot drink
Milk
- white cold drink
