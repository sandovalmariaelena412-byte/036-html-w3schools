HTML File Paths

Una ruta de archivo describe la ubicacion de un archivo dentro de la estructura de carpetas de un sitio web.

File Path Examples

Path Description
<img src="picture.jpg"> El archivo "picture.jpg" esta ubicado en la misma carpeta que la pagina actual
<img src="images/picture.jpg"> El archivo "picture.jpg" esta ubicado en la carpeta images dentro de la carpeta actual
<img src="/images/picture.jpg"> El archivo "picture.jpg" esta ubicado en la carpeta images en la raiz del sitio web actual
<img src="../picture.jpg"> El archivo "picture.jpg" esta ubicado en la carpeta un nivel arriba de la carpeta actual

Las rutas de archivo se usan al enlazar archivos externos, como paginas web, imagenes, hojas de estilo y JavaScript.

Absolute File Paths

Una ruta de archivo absoluta es la URL completa a un archivo.

Relative File Paths

Una ruta de archivo relativa apunta a un archivo en relacion a la pagina actual.

Archivo en la raiz del sitio actual

Archivo en la carpeta actual

Archivo un nivel arriba de la carpeta actual

Best Practice

Es una buena practica usar rutas de archivo relativas cuando sea posible.

Al usar rutas relativas, las paginas web no quedan atadas a la URL base actual. Todos los enlaces funcionaran tanto en la computadora local (localhost) como en el dominio publico actual y en futuros dominios.
