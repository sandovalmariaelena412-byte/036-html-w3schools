The HTML script Tag

La etiqueta script se usa para definir un script del lado del cliente (JavaScript). El elemento script contiene sentencias de script, o apunta a un archivo de script externo mediante el atributo src.

Usos comunes de JavaScript: manipulacion de imagenes, validacion de formularios, y cambios dinamicos de contenido.

Para seleccionar un elemento HTML, JavaScript usa mas frecuentemente el metodo document.getElementById().

The HTML noscript Tag

La etiqueta noscript define un contenido alternativo para mostrar a usuarios que tienen los scripts desactivados en su navegador, o cuyo navegador no soporta scripts.
