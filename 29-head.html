HTML - The Head Element

El elemento head es un contenedor para metadatos (datos sobre datos), y se coloca entre la etiqueta html y la etiqueta body.

Los metadatos no se muestran en la pagina. Normalmente definen el titulo del documento, el charset, estilos, scripts y otra informacion.

The HTML title Element

El elemento title define el titulo del documento. Debe ser solo texto, y se muestra en la barra de titulo del navegador o en la pestana. Es obligatorio en todo documento HTML.

El contenido del titulo es muy importante para el SEO (posicionamiento en buscadores), ya que los algoritmos de busqueda lo usan para decidir el orden al listar paginas en los resultados.

El elemento title: define un titulo en la barra del navegador, provee un titulo cuando se agrega a favoritos, y muestra un titulo en los resultados de busqueda.

The HTML style Element

El elemento style define informacion de estilo para una sola pagina HTML.

The HTML link Element

El elemento link define la relacion entre el documento actual y un recurso externo. Se usa mas frecuentemente para enlazar a hojas de estilo externas.

Ejemplo de sintaxis: <link rel="stylesheet" href="mystyle.css">

The HTML meta Element

El elemento meta se usa tipicamente para especificar el charset, la descripcion de la pagina, palabras clave, autor del documento, y ajustes de viewport. Los metadatos no se muestran en la pagina, pero son usados por navegadores, buscadores y otros servicios web.

Setting The Viewport

El viewport es el area visible de una pagina web para el usuario. Varia segun el dispositivo: es mas pequeno en un telefono que en una pantalla de computadora.

Esto le da al navegador instrucciones sobre como controlar las dimensiones y el zoom de la pagina.

La parte width=device-width ajusta el ancho de la pagina para que siga el ancho de pantalla del dispositivo.

La parte initial-scale=1.0 define el nivel de zoom inicial cuando la pagina se carga por primera vez.

The HTML script Element

El elemento script se usa para definir scripts del lado del cliente (JavaScript).

The HTML base Element

El elemento base especifica la URL base y/o el target por defecto para todos los enlaces relativos de una pagina. Debe tener el atributo href, target, o ambos. Solo puede haber un elemento base en el documento.

Ejemplo de sintaxis:

<head>
<base href="https://www.w3schools.com/" target="_blank">
</head>

<body>
<img src="images/stickman.gif" width="24" height="39" alt="Stickman">
<a href="tags/tag_base.asp">HTML base Tag</a>
</body>
